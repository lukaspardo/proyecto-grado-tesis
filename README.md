# Proyecto Integrador — Deuda técnica, SonarQube y LLM

Estudiamos si SonarQube y un modelo de lenguaje (LLM) pueden complementarse para identificar, interpretar y priorizar deuda técnica.

El enfoque actual es **investigativo**. Una futura prueba piloto permitirá explorar la propuesta; sus beneficios todavía deben evaluarse.

## Organización

La estructura aprobada se habilitará progresivamente:

| Ubicación | Contenido |
|---|---|
| `auditoria/` | Inventario de aportes y revisiones del proyecto. |
| `docs/aportes/` | Investigaciones por tema: `deuda_tecnica/`, `sonarqube/`, `llm/` y `metodologia/`. |
| `docs/matriz_rae/` | Formato RAE oficial del profesor y registros diligenciados de las fuentes revisadas. |
| `docs/documento_maestro.md` | Documento consolidado, gestionado por Santiago. |
| `material_profesor/` | Instrucciones, plantillas y observaciones originales del profesor. |
| `piloto/` | Código y resultados de la futura prueba piloto. |

## Cómo entregar tu investigación

1. Revisa tu Issue y el entregable solicitado.
2. Realiza la investigación e incluye fuentes identificables: autor, título, año y enlace o DOI cuando exista.
3. Sube el archivo a la carpeta temática correspondiente de `docs/aportes/`. Indica tu nombre, el número de Issue y la fecha.
4. Mueve la tarea a revisión, si esa opción está disponible, o comenta en el Issue que entregaste el aporte y dónde está.

Si la carpeta todavía no existe, adjunta el archivo al Issue e informa a Santiago.

**Flujo:** Issue → Investigación → Aporte → Revisión → Integración.

## Revisión e integración

Santiago revisa los aportes, solicita ajustes y gestiona su integración. Codex apoya la auditoría, comparación y consolidación; no sustituye la investigación ni la verificación de fuentes.

- **Entregar no equivale a aprobar.**
- Un Issue cerrado no implica que el contenido esté integrado.
- No modifiques directamente `docs/documento_maestro.md`.
- No modifiques los originales de `material_profesor/` ni los aportes recibidos de otros integrantes.
- No inventes fuentes ni presentes hipótesis como resultados comprobados.

Las reglas completas para Codex están en [AGENTS.md](AGENTS.md).

Las instrucciones y formatos oficiales del profesor tienen prioridad sobre cualquier convención interna del repositorio.
